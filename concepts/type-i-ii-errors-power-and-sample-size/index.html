01 The idea

Every statistical decision risks two fundamental mistakes: raising a false alarm when no effect exists (Type I error), or missing a genuine effect when one is present (Type II error). Statistical power measures a test's ability to detect true differences, and pre-experiment sample size planning guarantees that studies are neither underpowered nor wastefully oversized.

Think of a commercial smoke alarm system installed in an office. A Type I error ($\alpha$) is a false alarm: someone burns toast in the kitchen, triggering sirens and evacuating the entire building even though there is no actual blaze. A Type II error ($\beta$) is a missed detection: a genuine electrical fire starts in the server room, but the sensor fails to register the smoke. Statistical power ($1 - \beta$) is the system's true positive rate: the probability that the siren sounds given that a real fire has erupted.

Dialling up sensor sensitivity makes the alarm trigger at the faintest wisp of smoke, reducing missed detections (lowering $\beta$, boosting power) but causing more false alarms from routine cooking (increasing $\alpha$). Conversely, making the sensor less sensitive suppresses false alarms but leaves real fires undetected. In hypothesis testing, researchers fix the maximum acceptable false alarm rate in advance, typically setting $\alpha = 0.05$.

Once $\alpha$ is locked at 5%, how can an experimenter detect subtle effects without increasing false alarms? The only universal lever is collecting more data. Increasing sample size shrinks standard errors, sharpening the separation between the null and alternative distributions. For example, detecting a subtle uplift of Cohen's $d = 0.35$ with 80% power at $\alpha = 0.05$ requires exactly 129 participants per group. With only 30 participants per group, power plunges below 28%, meaning you are more than twice as likely to miss the true effect as to detect it.

In everyday terms

Balancing Type I and Type II errors is like setting the sensitivity on an airport metal detector: tune it too high and every belt buckle triggers an inspection; tune it too low and contraband passes through unnoticed.

02 Step by step

  1. Specify the significance threshold $\alpha$ (the maximum tolerable false positive rate, typically 0.05).
  2. Determine the minimum detectable effect (MDE) $\delta$ that is commercially or scientifically worthwhile to discover.
  3. Choose the desired statistical power $1 - \beta$ (typically 0.80 or 0.90, accepting a 10% to 20% risk of a false negative).
  4. Estimate baseline variance $\sigma^2$ from historical records or an exploratory pilot sample.
  5. Calculate the required per-group sample size $n$ using the analytical power equation prior to collecting any live data.
  6. Run the experiment to the full calculated sample size without early stopping or opportunistic peeking.

03 The maths

  1. The Decision Matrix and Error Probabilities

    $$\alpha = P(\text{Reject } H_0 \mid H_0 \text{ true}), \qquad \beta = P(\text{Fail to reject } H_0 \mid H_1 \text{ true})$$

    Type I error ($\alpha$, false positive rate) occurs when we reject a true null hypothesis. Type II error ($\beta$, false negative rate) occurs when we fail to reject a false null hypothesis. Statistical power is defined as the complement $1 - \beta = P(\text{Reject } H_0 \mid H_1 \text{ true})$, which corresponds to sensitivity or recall in binary classification.

  2. Two-Sample Mean Sample Size Formula

    $$n = \frac{2\left(z_{1 - \alpha/2} + z_{1 - \beta}\right)^2 \sigma^2}{\delta^2}$$

    For a two-sample $z$-test comparing means with common variance $\sigma^2$ and true difference $\delta = |\mu_1 - \mu_2|$, the required sample size per group $n$ scales with the squared critical normal quantiles. At $\alpha = 0.05$ ($z_{0.975} \approx 1.960$) and 80% power ($z_{0.80} \approx 0.842$), the numerator multiplier $(1.960 + 0.842)^2 \approx 7.85$.

  3. Standardised Effect Size (Cohen's d)

    $$d = \frac{|\mu_1 - \mu_2|}{\sigma} \implies n \approx \frac{2\left(z_{1 - \alpha/2} + z_{1 - \beta}\right)^2}{d^2}$$

    Cohen's $d$ expresses the effect size in units of standard deviations. Because $n$ is inversely proportional to $d^2$, detecting an effect half as large requires four times as many observations per group. Sizing studies to detect tiny effects without adequate sample sizes guarantees severe underpowering.

04 Key takeaways

  • Statistical power depends on four interconnected parameters: significance level $\alpha$, sample size $n$, effect size $\delta$, and population variance $\sigma^2$.
  • Required sample size scales inversely with the square of effect size: halving the target effect quadruples the required sample size.
  • Underpowered studies suffer from the winner's curse: when a small study does reach significance, its estimated effect size is substantially exaggerated.
  • Never compute retrospective or post-hoc power using observed p-values; power is an essential pre-experiment design tool, not an after-the-fact diagnostic.

05 In code

python
import numpy as np
import scipy.stats as stats

# Required sample size for two-sample test (Cohen's d = 0.35)
alpha = 0.05
target_power = 0.80
d = 0.35

z_alpha = stats.norm.ppf(1.0 - alpha / 2.0)  # ~1.960
z_beta = stats.norm.ppf(target_power)         # ~0.842
n_required = int(np.ceil(2.0 * ((z_alpha + z_beta) / d) ** 2))

# Verify statistical power through Monte Carlo simulation
rng = np.random.default_rng(42)
n_simulations = 2000
group_a = rng.normal(loc=0.0, scale=1.0, size=(n_simulations, n_required))
group_b = rng.normal(loc=d, scale=1.0, size=(n_simulations, n_required))

# Independent two-sample t-tests across all simulated trials
_, p_values = stats.ttest_ind(group_b, group_a, axis=1)
empirical_power = float(np.mean(p_values < alpha))

print(f"Cohen's d: {d}, alpha: {alpha}, target power: {target_power}")
print(f"Required sample size per group: {n_required}")
print(f"Empirical power ({n_simulations} trials): {empirical_power:.3f}")

Common pitfalls

  • Interpreting a non-significant result ($p > 0.05$) in an underpowered study as evidence of "no difference", when the study was simply blind to realistic effect sizes.
  • The winner's curse: deploying an algorithm or feature based on a tiny significant pilot test, only to discover performance collapses in production.
  • Continuous peeking: repeatedly checking p-values as users arrive and stopping the test the moment $p < 0.05$, which multiplies the true Type I error rate substantially above $\alpha$.
  • Confusing statistical power with sample representativeness: a huge sample size provides high power to detect differences, but cannot fix selection bias.

06 Check yourself

Q1In hypothesis testing, what constitutes a Type II error ($\beta$)?

Why: Type II error is a false negative: failing to reject $H_0$ despite a real effect existing in the underlying population.

Q2If you want to detect an effect size half as large as in a previous study (e.g. $d = 0.20$ instead of $0.40$) while keeping $\alpha$ and power constant, how does the required sample size change?

Why: Because the required sample size is proportional to $1/d^2$, halving the effect size ($d \to d/2$) multiplies the required sample size by $(2)^2 = 4$.

Q3What is the primary danger of the "winner's curse" in severely underpowered experiments?

Why: When power is low, only sample estimates that randomly overshoot the true mean by a huge margin cross the significance threshold, leading to severe upward bias in published effect estimates.

Q4How does continuous data peeking (checking p-values after every observation and stopping when $p < 0.05$) affect the experiment?

Why: Repeatedly testing accumulating data provides multiple opportunities for random noise to cross the threshold, inflating false positive rates well beyond nominal $\alpha$.
