1. Continuous Error Metrics Compared

Metric Formula Units Sensitivity to Outliers Key Strength
MSE $$\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2$$ $\text{Unit}^2$ Extremely High Differentiable; standard optimization loss.
RMSE $$\sqrt{\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2}$$ $\text{Unit}$ High Directly interpretable in target's natural units.
MAE $$\frac{1}{n} \sum_{i=1}^n |y_i - \hat{y}_i|$$ $\text{Unit}$ Low / Robust Represents expected absolute dollar/unit deviation.
R² (Determination) $$1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$ Unitless ($(-\infty, 1]$) Moderate Proportion of variance explained by model.
Adjusted R² $$1 - \left( \frac{1 - R^2}{n - p - 1} \right)(n - 1)$$ Unitless Moderate Penalizes introduction of irrelevant features.

2. Residual Diagnostics & Gauss-Markov Assumptions

A low RMSE is insufficient for model validation; reliable inference requires verifying residual assumptions:

The Four Classical Residual Checks
  • 1. Zero Mean: $\mathbb{E}[e_i] = 0$. Residuals must center around zero without systematic bias.
  • 2. Homoscedasticity: Constant error variance $\text{Var}(e_i|X) = \sigma^2$. Funnel-shaped residual plots indicate heteroscedasticity.
  • 3. Independence: $\text{Cov}(e_i, e_j) = 0$ for $i \ne j$. Checked via Durbin-Watson statistic for autocorrelation.
  • 4. Normality: Residuals follow a Gaussian distribution $e \sim \mathcal{N}(0, \sigma^2)$, validated using Q-Q plots.
