1. Internal Cluster Validity Diagnostics

Unsupervised clustering lacks ground truth labels. Validation relies on measuring intra-cluster cohesion versus inter-cluster separation.

Metric 1 / Tightness

Inertia (WCSS)

Within-Cluster Sum of Squares:

$$\text{WCSS} = \sum_{k=1}^K \sum_{x \in C_k} \|x - \mu_k\|^2$$

Used in the Elbow method to find inflection point where diminishing returns occur.

Metric 2 / Relative Cohesion

Silhouette Score

Measures how similar instance $i$ is to its own cluster versus the nearest neighboring cluster:

$$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$$

Range $[-1, +1]$. Values $> 0.5$ indicate robust, separable cluster boundaries.

Metric 3 / Dispersion Ratio

Davies-Bouldin Index

Ratio of within-cluster scatter to separation between cluster centroids. Lower scores indicate superior clustering.
