1. First-Order vs. Second-Order Optimization

Optimization algorithms balance convergence speed against computational cost per step:

First-Order / Gradient Descent

$\boldsymbol{\theta}_{k+1} = \boldsymbol{\theta}_k - \alpha \nabla f(\boldsymbol{\theta}_k)$

Relies strictly on first derivatives (steepest descent). In ill-conditioned ravines (anisotropic curvature), the gradient points almost perpendicularly to the optimal basin, causing violent oscillations and glacial progress.

$\text{Complexity: } O(p) \text{ time, } O(p) \text{ memory}$
Second-Order / Newton-Raphson

$\boldsymbol{\theta}_{k+1} = \boldsymbol{\theta}_k - \mathbf{H}_k^{-1} \nabla f(\boldsymbol{\theta}_k)$

Incorporates local curvature via the Hessian $\mathbf{H}_k = \nabla^2 f$. Steps directly target the center of the quadratic osculating bowl, exhibiting quadratic convergence (doubling accurate digits each step).

$\text{Complexity: } O(p^3) \text{ time, } O(p^2) \text{ memory}$
The Computational Roadblock

For modern datasets with $p = 10,000$ features, storing $\mathbf{H} \in \mathbb{R}^{p \times p}$ demands $10^8$ floats ($400\text{ MB}$), and computing $\mathbf{H}^{-1}$ via Gaussian elimination requires $O(p^3) = 10^{12}$ floating-point operations every single iteration. Full Newton is completely intractable for high-dimensional models.

2. The Quasi-Newton Paradigm & The Secant Condition

Quasi-Newton methods eliminate both the computation and inversion of the Hessian. Instead, they build an iterative approximation $\mathbf{B}_k \approx \mathbf{H}_k$ (or directly $\mathbf{H}_k \approx \mathbf{B}_k^{-1}$) utilizing only changes in parameter positions $\mathbf{s}_k$ and gradient differences $\mathbf{y}_k$:

$\mathbf{s}_k = \boldsymbol{\theta}_{k+1} - \boldsymbol{\theta}_k, \qquad \mathbf{y}_k = \nabla f(\boldsymbol{\theta}_{k+1}) - \nabla f(\boldsymbol{\theta}_k)$

The core mathematical requirement is the Secant Equation:

$\mathbf{H}_{k+1} \mathbf{y}_k = \mathbf{s}_k$

The BFGS Update Formula (Broyden-Fletcher-Goldfarb-Shanno, 1970) provides the rank-2 update preserving positive definiteness and symmetry:

$\mathbf{H}_{k+1} = (\mathbf{I} - \rho_k \mathbf{s}_k \mathbf{y}_k^T) \mathbf{H}_k (\mathbf{I} - \rho_k \mathbf{y}_k \mathbf{s}_k^T) + \rho_k \mathbf{s}_k \mathbf{s}_k^T, \quad \rho_k = \frac{1}{\mathbf{y}_k^T \mathbf{s}_k}$

3. L-BFGS & Two-Loop Recursion: The Industry Standard

While BFGS eliminates the $O(p^3)$ inversion, storing the dense $p \times p$ matrix $\mathbf{H}_k$ still consumes prohibitive $O(p^2)$ memory. Limited-Memory BFGS (L-BFGS) (Nocedal, 1980) completely discards the matrix $\mathbf{H}_k$!

The Limited-Memory History Buffer

Instead of maintaining a full matrix, L-BFGS retains only the $m$ most recent displacement pairs:

$\{(\mathbf{s}_i, \mathbf{y}_i)\}_{i=k-m}^{k-1}, \quad m \in [5, 20]$

Using the legendary Two-Loop Recursion algorithm, L-BFGS computes the exact descent direction $\mathbf{d}_k = -\mathbf{H}_k \mathbf{g}_k$ using only $4mp$ operations and $2mp$ memory storage!
