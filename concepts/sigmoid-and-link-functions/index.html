1. Definition & Inversion of the Logit Transformation

The standard Logistic Sigmoid function $\sigma(z)$ is the exact algebraic inverse of the logit transformation. Solving for probability $p$ in terms of linear score $z$:

$z = \ln\left(\frac{p}{1 - p}\right) \implies e^z = \frac{p}{1 - p} \implies p = e^z(1 - p) \implies p = \frac{e^z}{1 + e^z} = \frac{1}{1 + e^{-z}}$

Key mathematical checkpoints on the real number line:

Lower Asymptote

$\lim_{z \to -\infty} \sigma(z) = 0$

Predicts zero probability for overwhelmingly negative linear scores.

Inflection Threshold

$\sigma(0) = 0.50$

The exact decision hyperplane boundary where class odds are $1:1$.

Upper Asymptote

$\lim_{z \to +\infty} \sigma(z) = 1$

Predicts guaranteed certainty for strong positive linear evidence.

2. The Derivative & The Vanishing Gradient Problem

One of the most computational useful properties of the sigmoid function in calculus and backpropagation is that its first derivative is expressed entirely in terms of its output:

$\frac{d}{dz}\sigma(z) = \sigma(z)(1 - \sigma(z))$

Proof via Quotient / Chain Rule:

$\frac{d}{dz}(1 + e^{-z})^{-1} = -(1 + e^{-z})^{-2} \cdot (-e^{-z}) = \frac{e^{-z}}{(1 + e^{-z})^2} = \left(\frac{1}{1 + e^{-z}}\right) \left(\frac{e^{-z}}{1 + e^{-z}}\right) = \sigma(z)(1 - \sigma(z))$
The Vanishing Gradient Bottleneck in Deep Architectures

Because $\sigma(z) \in [0, 1]$, the quadratic product $\sigma(1 - \sigma)$ reaches an absolute maximum at $\sigma(z) = 0.5$ ($z=0$):

$\max \sigma'(z) = 0.5 \times (1 - 0.5) = 0.25$

When $|z| \ge 4$, $\sigma'(z) < 0.017 \to 0$. In deep neural networks, computing gradients via the chain rule multiplies these factors across $L$ layers: $\prod_{l=1}^L \sigma' \le (0.25)^L$. For a 10-layer network, $(0.25)^{10} \approx 9.5 \times 10^{-7}$, extinguishing parameter updates entirely. This prompted modern deep learning to adopt ReLU/GELU for hidden layers while retaining Sigmoid for binary probability heads.

3. Generalized Linear Models (GLMs) & Link Functions

In Generalized Linear Models (Nelder & Wedderburn, 1972), models are unified through three formal components:

Component A

Random Component

Target $Y$ drawn from an exponential family distribution (Bernoulli, Poisson, Gaussian, Gamma).

Component B

Systematic Linear Score

Linear combination of predictors:

$\eta = \mathbf{w}^T \mathbf{x} + b$
Component C

Link Function $g(\mu) = \eta$

Transforms distribution mean $\mu = \mathbb{E}[Y]$ to linear space $\eta$.

For Bernoulli distributions, the canonical link is the logit link $g(p) = \ln(p / (1-p))$, and its inverse link $g^{-1}(\eta) = \sigma(\eta)$ is the Logistic Sigmoid. Alternative link functions include the Probit Link (inverse normal CDF $\Phi^{-1}(p)$) and the asymmetric Complementary Log-Log (cloglog) link $\ln(-\ln(1 - p))$.
