01 The idea

EDA is the habit of understanding the data before fitting anything. Most modelling failures are data problems that a few plots and counts would have revealed.

A model only learns what is in the data, including its mistakes. EDA asks a fixed set of questions: What does each column look like? What is missing, and is it missing at random? Are there impossible values? How does each feature relate to the target, and to each other? Is anything suspiciously predictive, the kind of feature that would not be available at prediction time?

Skewed targets (house prices, incomes) often model better after a log transform. Heavy correlations between features warn of multicollinearity. Class imbalance changes which metric you should use. EDA finds these things early, when they are cheap to handle.

02 Step by step

  1. Shape and types: rows, columns, dtypes, ID columns, dates.
  2. Missingness: share missing per column, and whether it correlates with the target.
  3. Univariate distributions: histograms, skew, impossible values, outliers (IQR rule).
  4. Target: balance for classification; skew for regression.
  5. Bivariate: each feature against the target; correlation matrix; VIF for collinearity.
  6. Leakage check: anything recorded after the outcome, or too good to be true.

04 The maths

  1. Skewness

    $$g_1 = \frac{\frac1n\sum_i(x_i - \bar x)^3}{\big(\frac1n\sum_i(x_i - \bar x)^2\big)^{3/2}}$$

    Above about 1 in absolute value is strongly skewed; a log or Box-Cox transform often helps.

  2. IQR outlier rule

    $$x < Q_1 - 1.5\,\mathrm{IQR} \;\;\text{or}\;\; x > Q_3 + 1.5\,\mathrm{IQR}, \qquad \mathrm{IQR} = Q_3 - Q_1$$

    A flag for inspection, not an automatic delete.

  3. Variance inflation factor

    $$\mathrm{VIF}_j = \frac{1}{1 - R_j^2}$$

    $R_j^2$ comes from regressing feature $j$ on all the others. VIF above 5–10 signals collinearity that will destabilise linear models.

05 Key takeaways

  • Every EDA finding should become a decision: drop, transform, impute, engineer, or note as a risk.
  • Split off the test set before deep EDA, so its quirks do not leak into your choices.
  • Missing values are information: "missing income" may itself predict the target.

06 In code

python
import pandas as pd, numpy as np

df = pd.read_csv("datasets/raw/california_housing.csv")
print(df.shape, df.dtypes.value_counts().to_dict())
print(df.isna().mean().sort_values(ascending=False).head())       # missing share
print(df.skew(numeric_only=True).sort_values())                     # skew per column
q1, q3 = df.quantile(0.25), df.quantile(0.75)
print(((df < q1 - 1.5 * (q3 - q1)) | (df > q3 + 1.5 * (q3 - q1))).mean().round(3))  # outlier share
print(df.corr(numeric_only=True)["MedHouseVal"].sort_values())      # relation to target

Common pitfalls

  • Doing EDA on the full dataset, then being surprised the test score is optimistic.
  • Deleting outliers that are real and important (fraud, failures).
  • Imputing with the mean before splitting, which leaks test information into training.

07 Check yourself

Q1A feature has VIF = 12. What does that suggest?

Why: $R_j^2 = 1 - 1/12 \approx 0.92$ of its variance is explained by other features.

Q2Why should the test set be split off before detailed EDA?

Why: Decisions informed by test data make the final score optimistic.
