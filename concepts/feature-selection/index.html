Feature Selection & Dimensionality Reduction

Filter, wrapper, and embedded techniques to isolate informative signals, eliminate multicollinearity, and prevent the curse of dimensionality.

1. Taxonomy of Feature Selection Methods

Selecting an optimal subset of features improves model interpretability, accelerates training, mitigates overfitting, and removes noisy collinear predictors.

Type 1 / Independent

Filter Methods

Evaluate feature relevance using statistical scores independent of model training. Extremely fast and computationally scalable.

  • Pearson & Spearman Correlation
  • Mutual Information Gain
  • ANOVA F-statistic (Classification)
  • Variance Thresholding
Type 2 / Iterative

Wrapper Methods

Treat model training as a black-box evaluation metric, iteratively adding or pruning features to maximize cross-validation performance.

  • Recursive Feature Elimination (RFE)
  • Sequential Forward Selection (SFS)
  • Sequential Backward Elimination
  • Genetic Algorithm Search
Type 3 / Built-In

Embedded Methods

Feature selection is naturally embedded into the model objective function during loss optimization.

  • L1 Lasso Regularization Shrinkage
  • Elastic Net Group Sparsity
  • Tree Feature Importance (Gini / Gain)
  • Gradient Boosted Feature Importances

2. Diagnosing Multicollinearity: Variance Inflation Factor (VIF)

In linear models ($OLS$, Ridge, Logistic Regression), high collinearity between predictors inflates standard errors of coefficients, making parameter estimates wildly erratic and unstable.

The VIF Formulation

The Variance Inflation Factor for predictor $X_j$ measures how much of its variance is explained by all other predictors in the dataset:

$$\text{VIF}_j = \frac{1}{1 - R_j^2}$$

Where $R_j^2$ is the coefficient of determination obtained from regressing feature $X_j$ against all other remaining features.

  • $\text{VIF} = 1$: Complete orthogonality (no correlation with other features).
  • $\text{VIF} > 5$: Moderate multicollinearity; requires monitoring.
  • $\text{VIF} > 10$: Severe multicollinearity; inversion $(X^T X)^{-1}$ becomes ill-conditioned. Feature pruning or L2 Ridge shrinkage is required.

3. Decision Framework: Which Technique to Choose?

Data & Architecture Scenario Recommended Feature Selection Technique Core Engineering Justification
Linear Models (OLS, Ridge, Logistic) VIF Filtering + Pearson Correlation + Lasso (L1) Linear models are vulnerable to matrix singularity when features are collinear. VIF eliminates linear dependencies.
High-Dimensional Data ($p \gg n$) Mutual Information + L1 Lasso Shrinkage Filters zero-information noise quickly, then Lasso forces uninformative weights strictly to zero.
Tree Ensembles (Random Forest, XGBoost) Permutation Importance / SHAP Values Captures non-linear dependencies and feature interactions without assuming monotonic relationships.
