1. Loss Function vs. Cost Function vs. Objective Function

While often used interchangeably in casual discussion, mathematical optimization enforces strict distinctions between these core formulations:

01 / Instance Loss

Loss Function $\mathcal{L}(\hat{y}^{(i)}, y^{(i)})$

Measures the prediction error on a single training instance. It quantifies the penalty incurred when the model predicts $\hat{y}^{(i)}$ instead of true ground truth $y^{(i)}$.

02 / Aggregate Cost

Cost Function $J(\theta)$

The aggregate empirical expectation computed over the entire training dataset (or mini-batch), frequently augmented with a regularization penalty $\Omega(\theta)$:

$$J(\theta) = \frac{1}{n} \sum_{i=1}^n \mathcal{L}(\hat{y}^{(i)}, y^{(i)}) + \lambda \Omega(\theta)$$
03 / Optimization Goal

Objective Function

The most general mathematical formulation being minimized (loss) or maximized (reward, likelihood). In ML, our objective is to find $\hat{\theta} = \arg\min_\theta J(\theta)$.

2. Canonical Regression Loss Functions

The choice of loss function directly shapes the model's sensitivity to anomalies and the geometric properties of the optimization surface.

Loss Function Mathematical Formulation Gradient $\frac{\partial \mathcal{L}}{\partial \hat{y}}$ Robustness to Outliers Primary Use Cases
Mean Squared Error (MSE / L2) $$\mathcal{L} = \frac{1}{2}(y - \hat{y})^2$$ $$-(y - \hat{y})$$ Low (errors grow quadratically) OLS, Ridge, Polynomial Regression, Gaussian Process
Mean Absolute Error (MAE / L1) $$\mathcal{L} = |y - \hat{y}|$$ $$-\text{sgn}(y - \hat{y})$$ High (linear penalty on residuals) Median regression, financial datasets with heavy tails
Huber Loss (Smooth L1) $$\begin{cases} \frac{1}{2}e^2 & |e| \le \delta \\ \delta(|e| - \frac{1}{2}\delta) & \text{otherwise} \end{cases}$$ $$\begin{cases} -e & |e| \le \delta \\ -\delta\text{sgn}(e) & \text{otherwise} \end{cases}$$ Optimal (quadratic for small errors, linear for anomalies) Robust Regression, Gradient Boosting, Object Detection
Epsilon-Insensitive Loss $$\max(0, |y - \hat{y}| - \epsilon)$$ $$\begin{cases} 0 & |e| \le \epsilon \\ -\text{sgn}(e) & \text{otherwise} \end{cases}$$ High (ignores errors within margin tube $\epsilon$) Support Vector Regression (SVR)

3. Canonical Classification Loss Functions

Classification models map continuous logits $z = w^T x + b$ to discrete probabilities or margin boundaries:

Binary Cross-Entropy (Log Loss)

Derived directly from the negative log-likelihood of a Bernoulli distribution under maximum likelihood estimation (MLE):

$$\mathcal{L}_{\text{BCE}}(y, p) = - \left[ y \log(p) + (1 - y) \log(1 - p) \right], \quad p = \sigma(z) = \frac{1}{1 + e^{-z}}$$

When the true label is $y=1$ and predicted probability $p \to 0$, $\mathcal{L} \to \infty$, heavily penalizing overconfident incorrect predictions.

Hinge Loss (Support Vector Machines)

Enforces maximum-margin separation by penalizing points that violate or breach the margin boundary:

$$\mathcal{L}_{\text{Hinge}}(y, f(x)) = \max(0, 1 - y \cdot f(x)), \quad y \in \{-1, +1\}$$

If $y \cdot f(x) \ge 1$, the instance is correctly classified beyond the margin boundary and incurs zero loss.
