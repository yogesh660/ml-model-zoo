Loss Functions: How Models Measure Mistakes

MSE, MAE, Huber, log-loss and hinge: what each one punishes, and how that choice shapes the model you get.

01 The idea

The loss function is where you tell the model what a mistake costs. Squared loss hates big errors, absolute loss treats all errors evenly, log-loss hates confident wrong answers, hinge loss only cares about getting the margin right.

Minimising squared error gives the conditional mean; minimising absolute error gives the conditional median. That is why MSE is pulled by outliers and MAE is not. Huber is squared near zero and absolute far away: the best of both.

For classification, log-loss (cross-entropy) penalises a 0.99 prediction for the wrong class with $-\log 0.01 \approx 4.6$, a huge penalty, which pushes models toward calibrated probabilities. Hinge loss is zero once a point is correctly classified with margin at least 1, so it ignores easy points, which is why SVMs depend only on support vectors.

In everyday terms

A teacher’s marking scheme: does a big mistake cost a lot more than a small one, the same, or does only being on the right side of the line matter?

02 Step by step

  1. Regression: start with squared error; switch to Huber or MAE when outliers matter; use quantile (pinball) loss for prediction intervals.
  2. Classification: log-loss when you need probabilities; hinge for maximum-margin classifiers.
  3. Make sure the loss you train on matches what the business penalises.

04 The maths

  1. Regression losses

    $$\ell_{\text{MSE}} = (y - \hat y)^2, \quad \ell_{\text{MAE}} = |y - \hat y|, \quad \ell_\delta = \begin{cases}\tfrac12 e^2 & |e| \le \delta\\ \delta(|e| - \tfrac12\delta) & \text{otherwise}\end{cases}$$

    Their gradients tell the story: $2e$ grows without limit, $\operatorname{sign}(e)$ is constant, Huber is capped at $\pm\delta$.

  2. Classification losses (margin $m = y\,f(x)$, $y \in \{-1, 1\}$)

    $$\ell_{\text{log}} = \log(1 + e^{-m}), \quad \ell_{\text{hinge}} = \max(0, 1 - m), \quad \ell_{0/1} = \mathbb 1[m \le 0]$$

    Both log and hinge are convex upper bounds of the 0/1 loss, which we cannot optimise directly.

  3. Quantile (pinball) loss

    $$\ell_\tau(e) = \max(\tau e,\; (\tau - 1)e)$$

    Minimised by the $\tau$-th conditional quantile; used for prediction intervals with boosting.

05 Key takeaways

  • MSE → mean, MAE → median, pinball → quantile.
  • Convex surrogate losses make classification trainable.
  • The loss decides which errors the model will sacrifice to fix others.

06 In code

python
import numpy as np

e = np.linspace(-3, 3, 7)
mse, mae = e ** 2, np.abs(e)
huber = np.where(np.abs(e) <= 1, 0.5 * e ** 2, np.abs(e) - 0.5)
m = np.linspace(-2, 2, 5)                         # classification margins y*f(x)
log_loss, hinge = np.log1p(np.exp(-m)), np.maximum(0, 1 - m)
print(np.c_[e, mse, mae, huber]); print(np.c_[m, log_loss, hinge])

Common pitfalls

  • Training with MSE on data with heavy outliers and blaming the model.
  • Using accuracy as a training signal; it has zero gradient almost everywhere.

07 Check yourself

Q1Which loss is minimised by predicting the median?

Why: The derivative of $\sum|y_i - c|$ is zero where half the points are above $c$ and half below.

Q2Hinge loss for a correctly classified point with margin 2 is:

Why: $\max(0, 1 - 2) = 0$: points beyond the margin contribute nothing.
