1. From Probability to Odds to Log-Odds

A standard posterior probability $p = P(Y=1|X)$ is strictly constrained to the unit interval $p \in [0, 1]$. If we attempt to fit an unconstrained linear model directly to probabilities ($p = \mathbf{w}^T \mathbf{x} + b$), extreme feature values inevitably predict nonsensical probabilities $p < 0$ or $p > 1$, violating the Kolmogorov probability axioms.

01 / Probability

Bounded Interval $[0, 1]$

Measures absolute event likelihood: $p = \frac{n_{\text{success}}}{n_{\text{total}}}$. As $p \to 0$, event is impossible; as $p \to 1$, event is guaranteed.

02 / Odds Ratio

Semi-Infinite $[0, +\infty)$

Ratio of favorable to unfavorable outcomes:

$\text{Odds} = \frac{p}{1 - p}$

When $p=0.8$, $\text{Odds} = 4.0$ (4-to-1 in favor). When $p=0.5$, $\text{Odds} = 1.0$. Removes upper bound but retains zero floor.

03 / Logit (Log-Odds)

Unbounded $(-\infty, +\infty)$

Taking the natural logarithm yields the logit:

$\text{logit}(p) = \ln\left(\frac{p}{1 - p}\right)$

Maps $[0, 1] \to \mathbb{R}$, perfectly aligning with real-valued linear hyperplanes $\mathbf{w}^T \mathbf{x} + b$.

2. Interpreting Weights as Multiplicative Odds Ratios

In Logistic Regression, the systematic component models the log-odds directly as a linear combination:

$\ln\left(\frac{p}{1 - p}\right) = w_0 + w_1 x_1 + w_2 x_2 + \dots + w_p x_p$

Consider an increment of $\Delta x_1 = 1$ while holding all other features strictly constant:

$\text{logit}(p_{\text{new}}) - \text{logit}(p_{\text{old}}) = w_1 \implies \frac{\text{Odds}_{\text{new}}}{\text{Odds}_{\text{old}}} = e^{w_1}$
Weight Value $w_j$ Odds Ratio $\text{OR} = e^{w_j}$ Directional Effect Clinical / Practical Interpretation
$w_j = +0.693$ $e^{0.693} \approx 2.00$ Doubles Odds (+100%) Every unit increase doubles the odds of the positive outcome.
$w_j = 0.000$ $e^0 = 1.00$ Neutral (No Change) Feature has zero statistical association with the class label.
$w_j = -0.693$ $e^{-0.693} \approx 0.50$ Halves Odds (-50%) Every unit increase cuts the odds of the outcome in half.

3. Mathematical Symmetry & Asymptotic Saturation

Point Symmetry around the Decision Threshold

The logit function exhibits exact antisymmetric reflection about $p = 0.5$ ($ ext{logit} = 0$):

$\text{logit}(1 - p) = \ln\left(\frac{1 - p}{p}\right) = -\ln\left(\frac{p}{1 - p}\right) = -\text{logit}(p)$

A probability of $0.90$ produces $\text{logit}(0.90) = +2.197$, while its complementary error $0.10$ produces $\text{logit}(0.10) = -2.197$.

Asymptotic Compression & Certainty Penalties

As $p \to 1$, $\text{logit}(p) \to +\infty$; as $p \to 0$, $\text{logit}(p) \to -\infty$. Increasing probability from $50\%$ to $60\%$ requires $\Delta z = 0.405$, but pushing from $98\%$ to $99\%$ requires $\Delta z = 0.704$, and moving from $99.9\%$ to $99.99\%$ requires massive parameter shifts. This guarantees infinite penalties for confident false predictions.
