Loss Function vs. Cost Function vs. Error Function

Demystifying the precise mathematical taxonomy between instance loss, aggregate cost, and evaluation error in machine learning.

1. Side-by-Side Mathematical Comparison

Concept Mathematical Scope Optimization Role Example
Loss Function $\mathcal{L}(y, \hat{y})$ Single sample $(x_i, y_i)$ Differentiable target evaluated per instance $$\frac{1}{2}(y_i - \hat{y}_i)^2 \quad \text{or} \quad -y_i \log(p_i)$$
Cost Function $J(\theta)$ Full dataset or mini-batch Direct mathematical objective being optimized by solver $$\frac{1}{n} \sum_{i=1}^n \mathcal{L} + \lambda \|w\|^2$$
Error Function / Metric Evaluation benchmark Interpretable score for humans (often non-differentiable) $$\text{Accuracy}, \quad \text{ROC-AUC}, \quad \text{F1-Score}, \quad \text{RMSE}$$
