01 The idea

Divisive clustering works top-down. Put everything in one cluster, split it in two, then keep choosing a cluster to split (typically the one with the largest error) until you have $k$.

Agglomerative clustering makes many local decisions first; divisive makes the big decisions first, using the global structure. Bisecting k-means, the practical version, runs 2-means on one cluster at a time, which is fast and tends to produce clusters of more even size than plain k-means.

In everyday terms

Splitting a company into divisions, then each division into departments, always reorganising the largest or messiest unit next.

02 How it works

  1. Start with all points in one cluster.
  2. Pick the cluster to split (largest SSE or largest size).
  3. Split it with 2-means (several trials, keep the best).
  4. Repeat until there are $k$ clusters.

03 Try it

Things to try

04 The maths

  1. Which cluster to split

    $$C^* = \arg\max_{C}\sum_{x \in C}\lVert x - \mu_C\rVert^2$$

    The "biggest inertia" strategy; scikit-learn also offers splitting the largest cluster.

06 When to use it

Strengths

  • Faster than agglomerative on large data.
  • Big decisions use global structure.
  • Produces a hierarchy as a by-product.

Limitations

  • Greedy splits are never revisited.
  • Inherits k-means’ shape assumptions.

Reach for it when

Document clustering and large datasets where you want a hierarchy cheaply.

Think twice when

Non-convex shapes.

07 In code

python
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("datasets/raw/mall_customers.csv")
X = StandardScaler().fit_transform(df[["Annual_Income_k", "Spending_Score"]])
from sklearn.cluster import BisectingKMeans

bkm = BisectingKMeans(n_clusters=5, bisecting_strategy="biggest_inertia", random_state=0).fit(X)
print(bkm.labels_[:10])

Common pitfalls

  • Expecting identical results to agglomerative clustering; the trees are built very differently.
