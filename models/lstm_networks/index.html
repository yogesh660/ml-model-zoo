Long Short-Term Memory Networks (LSTMs)

An RNN with a separate memory cell and three gates (forget, input, output) that decide what to store, keep and reveal.

01 The idea

An LSTM keeps two things per step: a cell state $c_t$, a long-term memory that is only changed by small, gated additions, and a hidden state $h_t$, the part it shows to the rest of the network. Three gates control the flow: forget, input and output.

Picture the cell state as a conveyor belt running through time. At each step the forget gate $f_t$ decides how much of what is on the belt to keep, the input gate $i_t$ decides how much new information to place on it, and the output gate $o_t$ decides how much of the belt to reveal as $h_t$. Because the belt is updated by addition rather than repeated squashing, information (and gradient) can travel hundreds of steps.

The classic test is "remember something, ignore distractions, recall it later": a value appears at the start, then many irrelevant inputs follow, then the network must report the value. A vanilla RNN smears the value with every distractor. An LSTM opens its input gate once, closes it, holds the forget gate near 1, and opens the output gate at the end. The lab runs exactly this task.

In everyday terms

A safe with three doors: one to throw old things out, one to put new things in, one to show what is inside. Most of the time all three stay shut and the contents are kept intact.

02 How it works

  1. Compute three gates from $x_t$ and $h_{t-1}$: forget $f_t$, input $i_t$, output $o_t$ (each a sigmoid, 0 to 1).
  2. Propose new content $\tilde c_t = \tanh(W_c x_t + U_c h_{t-1})$.
  3. Update the cell: $c_t = f_t \odot c_{t-1} + i_t \odot \tilde c_t$ (keep some old, add some new).
  4. Reveal part of it: $h_t = o_t \odot \tanh(c_t)$.
  5. Initialise the forget-gate bias to about 1 so the network starts by remembering.

04 Try it

The memory task: a value arrives at step 1, then 20 distractor inputs, then the network must recall the value. Watch the cell state (the conveyor belt) and the three gates step by step, and compare with a plain RNN trying the same thing.

Things to try
  1. Press Play with the defaults: the input gate opens once, the forget gate holds, and the value is recalled almost exactly.
  2. Switch the input gate to "always open": distractors pour into the cell and recall falls apart.
  3. Lower the forget gate to 0.8: the stored value leaks away, just like the RNN.

05 The maths

  1. Gates

    $$f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f), \quad i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i), \quad o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o)$$

    Each gate is a vector the same size as the memory, so different units can keep or forget independently.

  2. Cell and hidden state

    $$c_t = f_t\odot c_{t-1} + i_t\odot\tilde c_t, \qquad h_t = o_t\odot\tanh(c_t)$$

    The cell state is updated additively: the key difference from an RNN.

  3. The gradient highway

    $$\frac{\partial c_t}{\partial c_{k}} = \prod_{s=k+1}^{t} \operatorname{diag}(f_s)$$

    Along the cell path, gradients are only scaled by forget gates. With $f_s \approx 1$, they reach far into the past without vanishing.

07 When to use it

Strengths

  • Long memory through the additive cell path.
  • Robust and well understood; strong on time series and speech.
  • Explicit gates are somewhat interpretable.

Limitations

  • About 4× the parameters of an RNN of the same width.
  • Sequential computation limits training speed.
  • Transformers usually win on large text datasets.

Reach for it when

Time-series forecasting, speech, handwriting, and text tasks with moderate data where long memory matters.

Think twice when

Very long contexts with lots of data and GPUs available: Transformers train faster and attend directly.

08 In code

python
import torch, torch.nn as nn
from sklearn.datasets import load_digits

# read each 8x8 digit image as a sequence: 8 time steps, 8 pixels per step
digits = load_digits()
X = torch.tensor(digits.images / 16.0, dtype=torch.float32)    # (n, 8, 8)
y = torch.tensor(digits.target)

class LSTMClassifier(nn.Module):
    def __init__(self, hidden=64):
        super().__init__()
        self.lstm = nn.LSTM(input_size=8, hidden_size=hidden, batch_first=True)
        self.out = nn.Linear(hidden, 10)
        # start by remembering: forget-gate biases (second quarter of each bias vector) set to 1
        for name, b in self.lstm.named_parameters():
            if "bias" in name:
                b.data[hidden:2 * hidden].fill_(1.0)

    def forward(self, x):
        _, (h_last, c_last) = self.lstm(x)
        return self.out(h_last[-1])

Common pitfalls

  • Leaving the forget-gate bias at 0, which makes the network forget by default early in training.
  • Confusing $h_t$ (what the LSTM shows) with $c_t$ (what it remembers).
  • Using an LSTM for tabular data with no meaningful order.

09 Check yourself

Q1Which gate decides how much of the old cell state to keep?

Why: $c_t = f_t \odot c_{t-1} + \dots$

Q2Why do gradients survive longer in an LSTM than in a vanilla RNN?

Why: Along the cell path the Jacobian is $\operatorname{diag}(f_t)$, close to the identity when $f_t \approx 1$.

Q3To remember a value and ignore 20 distractors, an LSTM ideally keeps:

Why: Write once, then hold; the output gate opens when the value is needed.
