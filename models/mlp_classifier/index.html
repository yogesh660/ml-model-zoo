01 The idea

Stack layers of neurons with non-linear activations between them, end with a softmax, and train everything jointly with backpropagation. Hidden layers learn intermediate features, which lets the network carve curved, even disconnected, decision regions.

Each hidden ReLU unit draws one line through the input space and outputs "how far past the line" a point is. The next layer combines these half-planes into polygons, curves and islands. That is how a two-layer network solves XOR, which no single perceptron can.

Training is Gradient descent on cross-entropy loss. Backpropagation applies the chain rule layer by layer to get every weight’s gradient in one backward sweep. Initialisation, learning rate, batch size, L2 penalty and early stopping all matter.

In everyday terms

A team where the first row of workers each draws one rule of thumb, and the second row learns how to combine those rules into a decision.

02 How it works

  1. Scale the inputs.
  2. Forward: $h = \text{ReLU}(W_1x + b_1)$, $p = \text{softmax}(W_2h + b_2)$.
  3. Loss: cross-entropy plus L2 penalty.
  4. Backward: propagate $\partial L/\partial z = p - y$ back through the layers.
  5. Update with Adam on mini-batches; stop early on validation loss.

04 The maths

  1. Softmax output and cross-entropy

    $$p_c = \frac{e^{z_c}}{\sum_{c'} e^{z_{c'}}}, \qquad L = -\sum_c y_c\log p_c, \qquad \frac{\partial L}{\partial z} = p - y$$

    The gradient at the output is simply "predicted minus true", just as in Logistic regression.

  2. Backpropagating through a hidden layer

    $$\delta_1 = (W_2^\top\delta_2)\odot\mathbb 1[z_1 > 0], \qquad \frac{\partial L}{\partial W_1} = \delta_1 x^\top$$

    The ReLU derivative is 1 where the unit was active and 0 elsewhere, so gradients only flow through active units.

06 When to use it

Strengths

  • Learns non-linear features automatically.
  • Scales with data and compute.
  • Same building block as modern deep learning.

Limitations

  • Many hyperparameters; sensitive to scaling and initialisation.
  • Often beaten by boosting on small tabular data.
  • Black box.

Reach for it when

Large datasets with complex structure, or when you will move on to deep architectures.

Think twice when

Small tabular datasets or when you need an interpretable model.

07 In code

python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neural_network import MLPClassifier

mlp = make_pipeline(StandardScaler(),
                    MLPClassifier(hidden_layer_sizes=(64, 32), alpha=1e-3, early_stopping=True,
                                  max_iter=1000, random_state=0)).fit(X_tr, y_tr)
print("test accuracy:", round(mlp.score(X_te, y_te), 3), "epochs:", mlp[-1].n_iter_)

Common pitfalls

  • Skipping input scaling.
  • Judging a network by a single training run; seeds matter.
  • Comparing to boosting without tuning either.
