Logistic Regression

Models class posterior log-odds via sigmoid link function, maximizing Bernoulli log-likelihood using quasi-Newton optimization (L-BFGS).

Essential Concepts: Confusion Matrix Precision, Recall & F1 ROC-AUC Curves Log Loss / Cross-Entropy Feature Selection Stratified CV

1. Intuition & Algorithmic Mental Model

How the Algorithm Solves Problems

Models class posterior log-odds via sigmoid link function, maximizing Bernoulli log-likelihood using quasi-Newton optimization (L-BFGS).

By framing learning as an explicit optimization task, this architecture establishes an optimal balance governed by the Bias-Variance Tradeoff, ensuring generalizability to unseen data.

Core Theoretical Assumptions

  • Data Generation: Assumes instances are independent and identically distributed ($i.i.d.$).
  • Feature Representation: Input space vectors $X$ are expected to be properly scaled via EDA and Preprocessing.
  • Optimization Surface: Relies on optimizing a mathematically rigorous Loss Function surface.

2. Step-by-Step Mathematical Derivation

Step 01 Sigmoidal Hypothesis & Binary Cross-Entropy (Log-Loss)
$$p(y=1 \mid x) = \sigma(w^T x + b) = \frac{1}{1 + e^{-(w^T x + b)}}, \quad \mathcal{L}_{\text{BCE}}(w) = -\frac{1}{n} \sum_{i=1}^n \left[ y_i \ln p_i + (1 - y_i) \ln(1 - p_i) \right]$$

Maps real-valued linear logits to calibrated probabilities $[0, 1]$ via the logistic sigmoid function, minimizing the negative log-likelihood of Bernoulli observations.

Step 02 Log-Loss Gradient & Iterative Optimization
$$\nabla_w \mathcal{L} = \frac{1}{n} X^T (p - y) \implies w^{(t+1)} = w^{(t)} - \eta \cdot \frac{1}{n} X^T (p - y)$$

The gradient exhibits a clean error-residual form $(p_i - y_i) x_i$. Because log-loss is strictly convex, gradient descent or L-BFGS is guaranteed to reach the global minimum.

Dataset Profile: Titanic Passenger Survival

Goal: Predict binary survival (1 = Survived, 0 = Deceased) across socio-demographic features including passenger class, age, gender, and fare.

Exploratory Data Analysis (EDA) Findings

1. Gender Dominance: Female survival rate was 74.2% versus male survival rate of 18.9%, making Sex the single most decisive split criterion.

2. Class Disparity: First-class passengers achieved 62.9% survival compared to 24.2% for third-class passengers.

3. Missing Values: Age contained ~20% missing entries, imputed using median age grouped by Pclass and Sex.

Feature Selection Decision & Rationale

Chosen Technique: Mutual Information Gain

Why this was selected:

Mutual information captures non-linear associations between mixed categorical variables (Sex, Pclass) and the discrete survival target without requiring parametric normality assumptions.

Dataset Profile: Breast Cancer Diagnostic

Goal: High-stakes clinical classification predicting Malignant vs. Benign cell nuclei.

Exploratory Data Analysis (EDA) Findings

1. Radius_Mean, Perimeter_Mean, and Area_Mean have correlation r > 0.98 (extreme geometric collinearity).

2. Asymmetric Cost: False Negatives (missing a malignant tumor) are catastrophic, meaning Recall must be prioritized over raw Accuracy.

Feature Selection Decision & Rationale

Chosen Technique: Correlation Pruning (r > 0.90) + RobustScaler

Why this was selected:

Removes redundant dimensional representations of cell size, isolating concavity and texture variations while maintaining an optimal 97.2% clinical Recall.

4. Architectural Trade-offs & Practitioner Guide

When to Choose this Architecture
  • When direct interpretability and explainability are mandatory for regulatory compliance.
  • When dataset volume is moderate and computational training budget is strictly limited.
  • When robust linear or well-conditioned relationships dominate after proper Feature Selection.
When NOT to Choose this Architecture
  • When complex, high-order non-linear feature interactions exist that simple kernels cannot capture.
  • When features exhibit extreme multicollinearity without applying Regularization (Ridge/Lasso).
  • When severe class imbalance makes standard accuracy misleading, requiring metric optimization for Recall & F1.
