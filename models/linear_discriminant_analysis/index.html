Linear Discriminant Analysis (LDA)

Models each class as a Gaussian with a shared covariance. The result is a linear boundary and a handy projection.

01 The idea

LDA assumes each class is a Gaussian blob with its own centre but the same shape. Under that assumption, Bayes’ rule gives a linear decision boundary, and the same maths gives the best projection for separating classes.

Logistic regression models $P(y\mid x)$ directly (discriminative). LDA models how the data in each class is generated, $P(x\mid y)$, and flips it with Bayes’ rule (generative). Because all classes share one covariance matrix, the quadratic terms cancel and the boundary is a hyperplane.

LDA also finds the directions that maximise between-class spread relative to within-class spread (Fisher’s criterion). With $K$ classes that gives up to $K-1$ dimensions, a supervised alternative to PCA for visualisation.

In everyday terms

Each class is a cloud of the same shape, just in a different place. Classify a point by asking which cloud it most plausibly came from.

02 How it works

  1. Estimate each class prior $\pi_k$ and mean $\mu_k$.
  2. Estimate one pooled covariance matrix $\Sigma$ from all classes.
  3. Compute a linear score $\delta_k(x)$ for every class.
  4. Predict the class with the highest score; or project onto the top discriminant directions.

04 The maths

  1. Generative model

    $$x \mid y = k \sim \mathcal N(\mu_k, \Sigma), \qquad P(y = k) = \pi_k$$

    One shared covariance $\Sigma$ for all classes is the key assumption.

  2. Linear discriminant

    $$\delta_k(x) = x^\top\Sigma^{-1}\mu_k - \tfrac12\mu_k^\top\Sigma^{-1}\mu_k + \log\pi_k$$

    The $x^\top\Sigma^{-1}x$ term is the same for every class and cancels, so the boundary between two classes is linear.

  3. Fisher’s criterion

    $$w^* = \arg\max_w \frac{w^\top S_B w}{w^\top S_W w}$$

    Maximise separation between class means relative to spread within classes. For two classes, $w^* \propto \Sigma^{-1}(\mu_1 - \mu_0)$.

05 Hyperparameters

06 When to use it

Strengths

  • Closed-form, fast, no tuning in the basic form.
  • Works well with small samples when the assumption holds.
  • Doubles as supervised dimensionality reduction.

Limitations

  • Assumes Gaussian classes with equal covariance.
  • Sensitive to outliers (means and covariances are not robust).
  • Linear boundary only.

Reach for it when

Small datasets, roughly Gaussian features, or when you want a supervised 2-D projection.

Think twice when

Classes with very different spreads (use QDA) or heavy outliers.

07 In code

python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

lda = LinearDiscriminantAnalysis(solver="lsqr", shrinkage="auto").fit(X_tr, y_tr)
print("test accuracy:", round(lda.score(X_te, y_te), 3))

projector = LinearDiscriminantAnalysis(n_components=1).fit(X_tr, y_tr)  # supervised projection
Z = projector.transform(X_te)

Common pitfalls

  • Applying LDA to categorical features coded as numbers; the Gaussian assumption makes no sense there.
  • Forgetting shrinkage when features outnumber samples.

09 Check yourself

Q1Why is the LDA boundary linear?

Why: With equal $\Sigma$, $x^\top\Sigma^{-1}x$ appears in every class’s score and drops out of the comparison.

Q2How many discriminant directions can LDA find for 4 classes?

Why: The between-class scatter matrix has rank at most $K - 1$.
