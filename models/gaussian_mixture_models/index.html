01 The idea

A GMM says each point was generated by one of $K$ Gaussians, chosen with probabilities $\pi_k$. The EM algorithm alternates between estimating which Gaussian each point probably came from (E-step) and refitting each Gaussian to its weighted points (M-step).

It is k-means with three upgrades: clusters can be elliptical and tilted (full covariance), different sizes, and assignments are probabilities rather than hard labels. In fact k-means is a GMM with equal, spherical covariances shrunk to zero.

Because it is a proper probability model, you can compare different $K$ values with BIC, compute the likelihood of new points (useful for anomaly detection), and sample new data.

In everyday terms

Explaining a crowd photo as several overlapping groups, each with its own centre and spread, and saying how likely each person belongs to each group.

02 How it works

  1. Initialise means (often with k-means), covariances and weights.
  2. E-step: compute responsibilities $\gamma_{ik}$, the probability point $i$ came from component $k$.
  3. M-step: update $\pi_k$, $\mu_k$, $\Sigma_k$ as responsibility-weighted estimates.
  4. Repeat until the log-likelihood stops improving; choose $K$ by BIC.

Things to try
  1. Use "elongated" blobs: GMM tilts its ellipses, k-means cannot.
  2. Switch covariance to spherical: it starts behaving like soft k-means.

04 The maths

  1. Mixture density

    $$p(x) = \sum_{k=1}^K\pi_k\,\mathcal N(x;\,\mu_k, \Sigma_k)$$

    Weights $\pi_k$ sum to 1.

  2. E-step

    $$\gamma_{ik} = \frac{\pi_k\mathcal N(x_i;\mu_k,\Sigma_k)}{\sum_j\pi_j\mathcal N(x_i;\mu_j,\Sigma_j)}$$

    Bayes’ rule for "which component produced this point".

  3. M-step

    $$N_k = \sum_i\gamma_{ik},\quad \pi_k = \frac{N_k}{n},\quad \mu_k = \frac{1}{N_k}\sum_i\gamma_{ik}x_i,\quad \Sigma_k = \frac{1}{N_k}\sum_i\gamma_{ik}(x_i - \mu_k)(x_i - \mu_k)^\top$$

    Weighted versions of the usual mean and covariance. Each EM iteration never lowers the likelihood.

06 When to use it

Strengths

  • Soft, probabilistic assignments.
  • Elliptical clusters of different sizes.
  • Principled model selection with BIC; density estimation for free.

Limitations

  • Assumes Gaussian components.
  • Local optima; sensitive to initialisation.
  • Full covariances need many parameters in high dimensions.

Reach for it when

Overlapping elliptical clusters, density estimation, anomaly scoring.

Think twice when

Non-convex shapes or very high-dimensional data with few rows.

07 In code

python
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("datasets/raw/mall_customers.csv")
X = StandardScaler().fit_transform(df[["Annual_Income_k", "Spending_Score"]])
from sklearn.mixture import GaussianMixture

bics = {k: GaussianMixture(k, covariance_type="full", n_init=5, random_state=0).fit(X).bic(X) for k in range(1, 9)}
best_k = min(bics, key=bics.get)
gmm = GaussianMixture(best_k, covariance_type="full", n_init=5, random_state=0).fit(X)
print("best k by BIC:", best_k, "soft memberships:", gmm.predict_proba(X[:3]).round(2))

Common pitfalls

  • Using full covariances with many features and few rows: singular matrices.
  • Comparing log-likelihoods across different K without a penalty such as BIC.
