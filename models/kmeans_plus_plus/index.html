01 The idea

k-means++ picks the first centre at random, then picks each next centre with probability proportional to its squared distance from the nearest centre already chosen. Starting centres end up spread across the data.

Random initialisation often drops two centres into the same cluster and none into another. k-means then has to drag them apart, often getting stuck. k-means++ makes far-away points much more likely to be chosen, so every real cluster tends to get a centre from the start.

It comes with a guarantee: the expected WCSS after seeding alone is within $O(\log k)$ of the optimum. In practice it means fewer iterations and fewer bad local minima, which is why it is scikit-learn’s default.

In everyday terms

Choosing meeting points for a scattered group: each new spot is chosen near the people who are currently farthest from any meeting point.

02 How it works

  1. Choose the first centre uniformly at random from the data.
  2. For each point, compute $D(x)$: the distance to its nearest chosen centre.
  3. Pick the next centre with probability $\propto D(x)^2$.
  4. Repeat until $k$ centres are chosen, then run standard k-means.

03 Try it

04 The maths

  1. Seeding distribution

    $$P(x_i \text{ chosen next}) = \frac{D(x_i)^2}{\sum_j D(x_j)^2}$$

    Squared distance makes far points much more likely without making the choice deterministic (which would favour outliers).

  2. Approximation guarantee

    $$\mathbb E[J_{\text{seed}}] \le 8(\ln k + 2)\,J_{\text{opt}}$$

    From Arthur and Vassilvitskii (2007).

06 When to use it

Strengths

  • Better solutions, fewer iterations.
  • Provable approximation bound.
  • Negligible extra cost.

Limitations

  • Seeding is sequential ($k$ passes over the data).
  • Can still pick an outlier as a centre.

Reach for it when

Always, whenever you run k-means.

Think twice when

Huge $k$ on huge data, where parallel variants (k-means‖) are faster.

07 In code

python
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("datasets/raw/mall_customers.csv")
X = StandardScaler().fit_transform(df[["Annual_Income_k", "Spending_Score"]])
from sklearn.cluster import KMeans

for init in ["random", "k-means++"]:
    runs = [KMeans(5, init=init, n_init=1, random_state=s).fit(X) for s in range(20)]
    print(init, "mean inertia", sum(r.inertia_ for r in runs) / 20, "mean iters", sum(r.n_iter_ for r in runs) / 20)

Common pitfalls

  • Assuming k-means++ removes the need to choose k. It only picks better starting points for the k you chose.
