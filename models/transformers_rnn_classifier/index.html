Recurrent Networks and Transformers for Sequences

Two ways to read a sequence: step by step with a memory (RNN, LSTM), or all at once with attention (Transformer).

01 The idea

A recurrent network reads tokens one at a time and carries a hidden state forward. A Transformer lets every token look directly at every other token through attention, all in parallel.

RNNs update a hidden state $h_t = \tanh(W h_{t-1} + U x_t)$. Information from early tokens must survive many multiplications by $W$ to reach the end, so gradients tend to vanish or explode. LSTMs and GRUs add gates and an additive cell state, which create a "highway" where information and gradients can flow with little decay.

Transformers drop recurrence. Each token produces a query, a key and a value. A token’s new representation is a weighted average of all values, weighted by how well its query matches each key. Distance no longer matters: the first and last word are one step apart. Positional encodings put order back in, and stacking layers and heads builds rich, context-dependent representations. For classification, a pooled token (e.g. [CLS]) feeds a softmax layer.

In everyday terms

An RNN reads a book once, front to back, keeping notes in a small notebook. A Transformer spreads every page on the table and draws lines between related sentences.

02 How it works

  1. Tokenise text and map tokens to embeddings (plus positional encodings for Transformers).
  2. RNN: run the recurrence over the sequence; use the last (or pooled) hidden state.
  3. Transformer: apply layers of multi-head self-attention and feed-forward blocks with residual connections and layer norm.
  4. Pool to one vector and classify with softmax.
  5. In practice, fine-tune a pre-trained Transformer rather than training from scratch.

Things to try
  1. Lower the temperature: attention becomes sharper, almost one-hot.
  2. Turn on the causal mask, as used in GPT-style models: each token only sees the past.
  3. Set the RNN weight scale to 0.8, then 1.2, and watch the gradient vanish or explode.

04 The maths

  1. Vanilla RNN and why gradients vanish

    $$h_t = \tanh(W_hh_{t-1} + W_xx_t + b), \qquad \frac{\partial h_T}{\partial h_k} = \prod_{t=k+1}^{T} \operatorname{diag}(\tanh'(\cdot))\,W_h$$

    A long product of matrices with norm below 1 shrinks toward zero; above 1 it explodes.

  2. LSTM cell state

    $$c_t = f_t \odot c_{t-1} + i_t \odot \tilde c_t$$

    When the forget gate $f_t \approx 1$, information passes through almost unchanged, so long-range gradients survive.

  3. Scaled dot-product attention

    $$\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V$$

    Dividing by $\sqrt{d_k}$ keeps dot products from growing with dimension, which would push the softmax into saturated, near one-hot regions with tiny gradients.

06 When to use it

Strengths

  • Transformers model long-range context and parallelise well.
  • Pre-trained models transfer to new tasks with little data.
  • LSTMs are compact and still good for streaming.

Limitations

  • Attention cost grows with the square of sequence length.
  • Large models are expensive to train and serve.
  • RNNs are sequential and slow to train on long inputs.

Reach for it when

Text, speech, event streams, any ordered data where context matters.

Think twice when

Short, bag-of-words-like tasks where a linear model on TF-IDF is nearly as good and far cheaper.

07 In code

python
from transformers import AutoTokenizer, AutoModelForSequenceClassification, pipeline

name = "distilbert-base-uncased-finetuned-sst-2-english"
clf = pipeline("text-classification",
               model=AutoModelForSequenceClassification.from_pretrained(name),
               tokenizer=AutoTokenizer.from_pretrained(name))
print(clf(["The delivery was late and the box was crushed.",
           "Setup took two minutes and it just works."]))

Common pitfalls

  • Training a Transformer from scratch on a small labelled set; fine-tune instead.
  • Truncating long documents silently and losing the part that carries the label.
  • Reading attention weights as explanations; they show where information flows, not why.

08 Check yourself

Q1What problem do LSTM gates mainly address?

Why: The additive, gated cell state lets information and gradients pass through many steps.

Q2Why is attention scaled by $1/\sqrt{d_k}$?

Why: Dot products of random vectors have variance proportional to $d_k$.

Q3How does self-attention’s cost grow with sequence length $T$?

Why: Every token attends to every other token: a $T \times T$ score matrix.
