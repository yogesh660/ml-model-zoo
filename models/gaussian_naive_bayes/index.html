01 The idea

Naive Bayes applies Bayes’ rule with one bold simplification: given the class, every feature is independent. For continuous features, each one gets its own 1-D Gaussian per class.

Estimating a full joint distribution over many features needs huge amounts of data. Assuming independence breaks it into one tiny 1-D problem per feature and class: just a mean and a variance. Training is a single pass over the data.

The assumption is almost never true, but for classification you only need the ranking of class probabilities to be right, not the probabilities themselves. That is why Naive Bayes often classifies well while being badly calibrated.

In everyday terms

Judging each piece of evidence separately and multiplying the odds together, as if no two clues were related.

02 How it works

  1. For each class, compute the prior $\pi_k$.
  2. For each class and feature, compute the mean and variance.
  3. For a new point, add up the log-likelihood of each feature under each class plus the log prior.
  4. Predict the class with the highest total.

04 The maths

  1. Naive Bayes decision rule

    $$\hat y = \arg\max_k \;\log\pi_k + \sum_{j=1}^p \log \mathcal N(x_j;\, \mu_{kj}, \sigma_{kj}^2)$$

    Independence turns the joint likelihood into a product, so the log-likelihood is a sum over features.

06 When to use it

Strengths

  • Extremely fast; one pass to train.
  • Works with very little data.
  • Handles many features gracefully.

Limitations

  • Independence assumption ignores correlated features (they are double-counted).
  • Probabilities are poorly calibrated.
  • Each feature must be roughly Gaussian within a class.

Reach for it when

A fast baseline, streaming data, or very small datasets.

Think twice when

Strongly correlated features or when you need trustworthy probabilities.

07 In code

python
from sklearn.naive_bayes import GaussianNB
from sklearn.calibration import CalibratedClassifierCV

nb = GaussianNB().fit(X_tr, y_tr)
print("accuracy:", round(nb.score(X_te, y_te), 3))
calibrated = CalibratedClassifierCV(GaussianNB(), method="isotonic", cv=5).fit(X_tr, y_tr)

Common pitfalls

  • Feeding it duplicated or highly correlated features: their evidence is counted twice.
  • Trusting predict_proba as real probabilities without calibration.
